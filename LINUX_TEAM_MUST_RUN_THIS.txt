═══════════════════════════════════════════════════════════════════════════════
🔍 WHY collectstatic IS MANDATORY
═══════════════════════════════════════════════════════════════════════════════

Django has 2 locations for static files:

SOURCE: /var/www/asset_tracker/assets/static/assets/css/styles.css
        ↑ This is where you COPY the new file

SERVED: /var/www/asset_tracker/staticfiles/assets/css/styles.css
        ↑ This is where NGINX SERVES the file from

collectstatic COPIES from SOURCE → SERVED

Without collectstatic:
- New CSS is in SOURCE
- Old CSS still in SERVED
- Nginx serves OLD CSS
- Users see NO changes!

🚨 IF STILL NOT WORKING
═══════════════════════════════════════════════════════════════════════════════

If you ran ALL commands and it STILL doesn't work:

Problem A: Wrong staticfiles directory
──────────────────────────────────────
Check settings.py for STATIC_ROOT:

grep STATIC_ROOT /var/www/asset_tracker/asset_tracker/settings.py

The path shown is where collectstatic puts files.
Make sure that's where Nginx is configured to serve from!

Problem B: Nginx not serving from staticfiles
─────────────────────────────────────────────
Check Nginx config:

cat /etc/nginx/sites-enabled/asset_tracker | grep static

Should show something like:
  location /static/ {
    alias /var/www/asset_tracker/staticfiles/;
  }

Problem C: Permissions wrong
────────────────────────────
sudo chown -R www-data:www-data /var/www/asset_tracker/staticfiles
sudo chmod -R 755 /var/www/asset_tracker/staticfiles

Problem D: SELinux blocking (RedHat/CentOS)
───────────────────────────────────────────
sudo chcon -R -t httpd_sys_content_t /var/www/asset_tracker/staticfiles/
