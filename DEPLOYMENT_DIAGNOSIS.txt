═══════════════════════════════════════════════════════════════════════════════
💡 WHY collectstatic IS SO CRITICAL
═══════════════════════════════════════════════════════════════════════════════

Django has TWO locations for static files:

1. SOURCE location:
   /var/www/asset_tracker/assets/static/assets/css/styles.css
   ↑ This is where YOU put the CSS file

2. SERVED location:
   /var/www/asset_tracker/staticfiles/assets/css/styles.css
   ↑ This is where NGINX reads the CSS file from

When you run collectstatic, it COPIES from (1) to (2).

If you DON'T run collectstatic:
- New CSS is in source location (1)
- But NGINX still serves old CSS from (2)
- Users see OLD styles!

This is why collectstatic is MANDATORY for CSS changes!
