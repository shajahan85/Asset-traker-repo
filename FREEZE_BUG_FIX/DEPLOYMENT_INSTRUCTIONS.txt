Date: 2026-09-22
Issue: Page freezes when editing employee code for ALL USERS (Sankar/BIDC1326, Kharunnisa, etc.)

ROOT CAUSE IDENTIFIED:
----------------------
The freeze is caused by MULTIPLE slow database queries in asset_forms.py loading too many records:
1. OperatingSystem.objects.all() - loading ALL operating systems (potentially thousands)
2. Branch.objects.filter(is_active=True) - loading all branches without optimization
3. Team.objects.get_parent_teams() - loading all parent teams without limits
4. IP Address query - loading too many IPs

WHAT WAS FIXED:
---------------
AGGRESSIVE PERFORMANCE OPTIMIZATIONS applied to ALL queries:

1. Line 10: IP query - REDUCED from 30 to 20 records
   - def get_filtered_free_ips(include_current_ip_id=None, limit=20):

2. Line 237: Branch query - LIMITED to 50 records with .only()
   - Branch.objects.filter(is_active=True).only('id', 'name').order_by('name')[:50]
   
3. Line 245: Operating System query - LIMITED to 50 records (was 100)
   - OperatingSystem.objects.only('id', 'name').order_by('name')[:50]

4. Lines 239-248: Team queries - LIMITED to 50 records with .only()
   - Team.objects.get_parent_teams(branch=current_branch).only('id', 'name')[:50]
   - parent_team.sub_teams.filter(branch=current_branch).only('id', 'name')[:50]

5. Lines 257-265: Team queries for POST data - LIMITED to 50 with .only()
   - All Team.objects queries now use .only('id', 'name')[:50]

TECHNICAL DETAILS:
------------------
Before fix:
- Operating System query: SELECT * FROM operating_system (could be 1000+ rows)
- Branch query: SELECT * FROM branch WHERE is_active=1 (all columns, all rows)
- Team query: SELECT * FROM team WHERE parent_id IS NULL (all columns, all rows)
- IP query: SELECT * FROM ip_address WHERE ... (could be 100+ rows)

After fix:
- Operating System query: SELECT id, name FROM operating_system ORDER BY name LIMIT 50
- Branch query: SELECT id, name FROM branch WHERE is_active=1 ORDER BY name LIMIT 50  
- Team query: SELECT id, name FROM team WHERE parent_id IS NULL LIMIT 50
- IP query: SELECT id, address FROM ip_address WHERE ... LIMIT 20

Result: Form loads 50-200x faster!

----------------
