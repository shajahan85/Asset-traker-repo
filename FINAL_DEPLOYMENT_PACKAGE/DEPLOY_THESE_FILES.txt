🚀 DEPLOYMENT INSTRUCTIONS FOR LINUX TEAM
═══════════════════════════════════════════════════════════════════════════════

ASSUMPTION: Linux server path is /var/www/asset_tracker/

If different, replace /var/www/asset_tracker/ with actual path.

────────────────────────────────────────────────────────────────────────────────
STEP 1: Upload this entire folder to Linux server
────────────────────────────────────────────────────────────────────────────────

Option A: Using SCP
scp -r FINAL_DEPLOYMENT_PACKAGE user@server:/tmp/

Option B: Using SFTP/WinSCP
Upload FINAL_DEPLOYMENT_PACKAGE folder to /tmp/

Option C: Copy to network share
Copy folder to accessible location

────────────────────────────────────────────────────────────────────────────────
STEP 2: On Linux server, run these commands
────────────────────────────────────────────────────────────────────────────────

# Stop services
sudo systemctl stop asset_tracker
sudo systemctl stop nginx

# Go to upload location
cd /tmp/FINAL_DEPLOYMENT_PACKAGE

# Copy ALL files (this copies everything in correct structure)
sudo cp -r assets/* /var/www/asset_tracker/assets/

# Set permissions
sudo chown -R www-data:www-data /var/www/asset_tracker/assets
sudo chmod -R 755 /var/www/asset_tracker/assets

# Go to project directory
cd /var/www/asset_tracker

# Activate virtual environment
source venv/bin/activate

# ⭐ CRITICAL: Collect static files
python manage.py collectstatic --clear --noinput

# Restart services
sudo systemctl start asset_tracker
sudo systemctl start nginx

# Verify services running
sudo systemctl status asset_tracker
sudo systemctl status nginx

────────────────────────────────────────────────────────────────────────────────
STEP 3: Verify deployment
────────────────────────────────────────────────────────────────────────────────

# Check bug fix deployed
grep "limit=30" /var/www/asset_tracker/assets/forms/asset_forms.py

# Check CSS collected
ls -la /var/www/asset_tracker/staticfiles/assets/css/styles.css

# Check CSS has fixes
grep "overflow-y.*auto" /var/www/asset_tracker/staticfiles/assets/css/styles.css
grep "max-height.*70vh" /var/www/asset_tracker/staticfiles/assets/css/styles.css

# Check logs for errors
sudo journalctl -u asset_tracker -n 20 --no-pager

────────────────────────────────────────────────────────────────────────────────
STEP 4: Verify in browser (USER)
────────────────────────────────────────────────────────────────────────────────

1. Clear browser cache (Ctrl + Shift + Delete → All time)
2. Close browser completely
3. Open in Incognito/Private window
4. Login to site
5. Check:
   ✅ Table has scrollbar on right side
   ✅ Table limited to screen height
   ✅ Header stays fixed when scrolling
   ✅ Edit asset loads fast (no freeze)
