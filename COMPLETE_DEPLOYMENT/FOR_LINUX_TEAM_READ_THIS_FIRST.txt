═══════════════════════════════════════════════════════════════════════════════
⚠️  MOST IMPORTANT COMMAND (90% of problems)
═══════════════════════════════════════════════════════════════════════════════

THIS COMMAND IS CRITICAL:

    cd /var/www/asset_tracker
    source venv/bin/activate
    python manage.py collectstatic --clear --noinput

If you skip this, CSS changes will NEVER appear!

Django stores static files (CSS, JS, images) in a SEPARATE location called
"staticfiles". When you copy CSS to assets/static/, Django doesn't use it
directly. You MUST run collectstatic to copy it to staticfiles/ directory.
