================================================================================
MANUAL FIREWALL CONFIGURATION
================================================================================

If the batch file doesn't work, add firewall rule manually:

METHOD 1: Using Command Prompt (Run as Administrator)
------------------------------------------------------
1. Press Win + X
2. Select "Command Prompt (Admin)" or "PowerShell (Admin)"
3. Run this command:

   netsh advfirewall firewall add rule name="Django Asset Tracker" dir=in action=allow protocol=TCP localport=8000

4. You should see: "Ok."


METHOD 2: Using Windows Firewall GUI
------------------------------------------------------
1. Press Win + R, type: wf.msc, press Enter
2. Click "Inbound Rules" in left panel
3. Click "New Rule..." in right panel
4. Select "Port" → Next
5. Select "TCP" and enter port: 8000 → Next
6. Select "Allow the connection" → Next
7. Check all profiles (Domain, Private, Public) → Next
8. Name: Django Asset Tracker → Finish

================================================================================
COMMON ISSUES AND SOLUTIONS
================================================================================

ISSUE 1: "This site can't be reached" or "Connection timed out"
----------------------------------------------------------------
CAUSE: Windows Firewall is blocking port 8000
SOLUTION: Add firewall rule using Method 1 or 2 above

ISSUE 2: "Connection refused"
----------------------------------------------------------------
CAUSE: Django server is not running
SOLUTION: 
1. Open Command Prompt in D:\Asset tracker
2. Run: python manage.py runserver 0.0.0.0:8000

ISSUE 3: Can access from server but not from network
----------------------------------------------------------------
CAUSE: Server is running on 127.0.0.1 instead of 0.0.0.0
SOLUTION: Make sure to use 0.0.0.0:8000 when starting server

ISSUE 4: "Access denied" when adding firewall rule
----------------------------------------------------------------
CAUSE: Not running as Administrator
SOLUTION: Right-click Command Prompt/PowerShell → Run as Administrator

ISSUE 5: Different IP address
----------------------------------------------------------------
CAUSE: Server has multiple network adapters
SOLUTION: 
1. Run: ipconfig
2. Find the IPv4 address starting with 192.168
3. Use that IP address to access from network

LocalPort:                            8000
Protocol:                             TCP

================================================================================
KEEPING SERVER RUNNING
================================================================================

The Django development server will stop if:
- You close the Command Prompt window
- You press CTRL+C
- The computer restarts
- There's an error in the code

To keep it running:
1. Don't close the Command Prompt window
2. Minimize it instead
3. Or use the start_server.bat file

For production use, consider:
- Using a proper web server (Apache, Nginx)
- Running as a Windows Service
- Using a process manager
